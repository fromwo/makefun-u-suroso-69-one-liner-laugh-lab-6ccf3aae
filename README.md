A tiny program for make.fun's "One-Liner Laugh Lab" bounty: it writes one original short funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`. Node standard library only, no network, no dependencies, deterministic output.

## Run it

```sh
node main.ts
```

Set `OUTPUT_PATH` to write the entry somewhere else, e.g. `OUTPUT_PATH=output/entry.txt node main.ts`.
